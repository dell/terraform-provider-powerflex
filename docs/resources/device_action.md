# powerflex_device_action (Resource)

This resource is used to perform Gen2 device actions on PowerFlex systems (5.0+). Supported actions: `activate`, `clear_error`, `set_capacity_limit`.

resource "powerflex_device_action" "example" {
  device_id = "device_id"
  action    = "activate"
}

After the execution of above resource block, device action would have been performed on the PowerFlex array. For more information, please check the terraform state file.
